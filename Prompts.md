# Learning Prompts — Registration Wizard

This file contains the prompts used during the development of the Registration Wizard project for learning, understanding concepts, troubleshooting, and improving implementation skills.

---

## 1. Understanding the Project Requirements

### Prompt
> Explain this registration wizard assignment to me in beginner-friendly language. Break down what the project is supposed to do, what technologies I need to know, and what each requirement means. Don't give me the code yet because I want to understand the assignment first.

---

## 2. Understanding React Components

### Prompt
> Explain React components to me as a beginner. Why would I separate a multi-step registration form into different components instead of keeping everything inside App.jsx?

---

## 3. Understanding Component Structure

### Prompt
> Suggest a clean folder structure for a React project containing a sidebar, three registration steps, and a success screen. Explain what each component is responsible for.

---

## 4. Understanding Props

### Prompt
> Explain React props in the context of a multi-step registration form. How can a parent component pass data and functions to child components?

---

## 5. Understanding State Lifting

### Prompt
> Explain state lifting in React using a multi-step registration form as an example. Why should the form data be stored in the parent component instead of separately inside each step?

---

## 6. Understanding Controlled Inputs

### Prompt
> Explain controlled inputs in React in beginner-friendly language. What is the relationship between an input's value, state, and onChange event?

---

## 7. Understanding Conditional Rendering

### Prompt
> Explain conditional rendering in React and show how it can be used to display different sections of a multi-step form depending on the current step.

---

## 8. Understanding useState

### Prompt
> Explain the useState hook in React with a simple example. Also explain what happens when state changes and why the component renders again.

---

## 9. Understanding Form Navigation

### Prompt
> Explain how Next and Back navigation normally works in a multi-step React form. What should happen to the current step when each button is clicked?

---

## 10. Understanding Form Validation

### Prompt
> Explain client-side form validation in React. What is the purpose of validating form fields before allowing the user to continue to the next step?

---

## 11. Understanding Email Regex

### Prompt
> Explain this email validation regex in simple terms:
>
> `^[^\s@]+@[^\s@]+\.[^\s@]+$`
>
> Break down what each part means and explain why it is useful for email validation.

---

## 12. Understanding Password Validation

### Prompt
> Explain how to validate that a password contains at least 8 characters in React. Also explain how this validation can be connected to the Continue button.

---

## 13. Understanding Confirm Password Validation

### Prompt
> Explain how confirm-password validation works in a registration form. How can I check that the confirmation password matches the original password?

---

## 14. Understanding Disabled Buttons

### Prompt
> Explain how and why a button can be disabled in React based on form validation. Give me a simple example of the logic without building the whole project for me.

---

## 15. Understanding Real-Time Validation

### Prompt
> What is real-time form validation? Explain how validation can happen while the user is typing instead of only after clicking Submit.

---

## 16. Understanding HTML Form Buttons

### Prompt
> Explain the difference between `type="button"` and `type="submit"` for buttons inside an HTML form. Why can using the wrong type cause unexpected form submission?

---

## 17. Understanding Password Input Types

### Prompt
> Explain the difference between `type="password"` and `type="text"` for an input field. How does a browser provide password visibility controls?

---

## 18. Understanding Progress Indicators

### Prompt
> Explain how a progress indicator works in a three-step registration wizard. How can the percentage be calculated from the current step?

---

## 19. Understanding CSS Component Styling

### Prompt
> Explain how I can organize CSS for a React project where each component has its own CSS file. What are the advantages of keeping component-specific styles separate?

---

## 20. Understanding Responsive Design

### Prompt
> Explain how responsive CSS works for a registration wizard. What should I consider when the sidebar needs to disappear or change layout on smaller screens?

---

## 21. Understanding React Event Handling

### Prompt
> Explain React's onChange and onClick events with simple examples. How are they commonly used in forms and navigation?

---

## 22. Debugging a React Component

### Prompt

## 24. Understanding Vite

## 32. Interview Preparation

### Prompt
> Give me beginner-friendly interview questions based on a React multi-step registration wizard project. Focus on React state, props, controlled inputs, conditional rendering, validation, and component structure.

---

## 33. Improving My Understanding

### Prompt
> Instead of giving me the complete solution, ask me questions that test whether I understand how a multi-step React registration form works. Correct my answers when I make mistakes.

---

## 34. Code Explanation

### Prompt
> I will provide a React code snippet from my project. Explain it line by line in beginner-friendly language and tell me why each important part is needed.

---

## 35. Debugging Approach

### Prompt
> When I encounter an error in my React project, teach me how to identify the cause step by step instead of immediately giving me a replacement solution.

---

## Learning Focus

The main concepts explored through these prompts were:

- React components
- Props
- State management
- State lifting
- Controlled inputs
- Conditional rendering
- Event handling
- Form validation
- Regular expressions
- Responsive CSS
- Vite
- Git
- GitHub
- Production builds
- Vercel deployment

> Note: Advanced form architecture using React Hook Form and schema validation with Zod was identified as a future improvement but was not implemented in the current version.
